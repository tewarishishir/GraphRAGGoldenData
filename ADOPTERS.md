# Adopters

This page lists organizations and individuals who use GraphRAGGoldenData — in production, in a pilot, for research, or as a reference for building their own golden-record and knowledge-graph pipelines.

Being listed helps the project show real-world value and helps new users find others with similar use cases.

## How to add yourself

1. Fork the repository.
2. Add a row to the table below (keep it alphabetical by organization).
3. Open a pull request titled `Add <Organization> to ADOPTERS`.

Only add an organization if you are authorized to represent it publicly. Individuals and open-source projects are welcome too.
